## 🚀 Featured Projects

### 🔬 [Semantic Segmentation for Autonomous Driving](https://github.com/adhilqather/semantic-seg-ad)
**PyTorch • Detectron2 • Cityscapes • ONNX • TensorRT**  
Real-time semantic segmentation pipeline optimized for edge deployment. Achieved **45 FPS on Jetson Orin** with mIoU 78.3% on Cityscapes val. Includes quantization-aware training, TensorRT optimization, and ROS2 integration.

### 🎯 [Multi-Object Tracking with YOLOv8 + DeepSORT](https://github.com/adhilqather/mot-yolo-deepsort)
**PyTorch • YOLOv8 • DeepSORT • MOT17 • ONNX**  
End-to-end MOT pipeline with ReID feature extraction. MOTA **68.2% on MOT17 test**. Deployable as TensorRT engine with **<30ms latency** per frame. Includes Kalman filter tuning and appearance model ablation studies.

### 🏗 [3D Gaussian Splatting for Novel View Synthesis](https://github.com/adhilqather/3dgs-reconstruction)
**PyTorch • CUDA • COLMAP • Nerfstudio • Open3D**  
Real-time 3D reconstruction from sparse views. Implemented differentiable Gaussian rasterization from scratch. Achieves **120+ FPS rendering** at 1080p with PSNR 28.4 on Mip-NeRF 360 dataset.

### 🔍 [Foundation Model Fine-tuning for Medical Imaging](https://github.com/adhilqather/medical-vlm-finetune)
**PyTorch • CLIP • LoRA • MedCLIP • MONAI • HuggingFace**  
Parameter-efficient fine-tuning of vision-language models for radiology report generation. **LoRA rank 16** achieves 94% of full fine-tuning performance with **0.3% trainable params**. Includes clinical evaluation protocol.

### 📊 [CVAT Annotation Pipeline with Active Learning](https://github.com/adhilqather/active-learning-annotation)
**Python • CVAT SDK • scikit-learn • ModAL • FastAPI • React**  
Active learning loop reducing annotation effort by **40%** for defect detection. Uncertainty sampling + diversity selection. Integrated with CVAT for human-in-the-loop workflow.
